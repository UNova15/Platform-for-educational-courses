# Функциональные требования

# Роль: Пользователь

Данная роль присваивается всем не аутентифицированным пользователям системы. Как только пользователь
зарегистрировался/вошел в аккаунт его роль меняется. Для своего курса пользователь будет иметь роль преподавателя, для
сторонних курсов пользователь будет иметь роль студента.

## Регистрация

**Как новый пользователь, я хочу зарегистрироваться по логину и паролю, чтобы получить доступ к личному кабинету.**

Критерии приемки:

- **Успешная регистрация:**
    + Пользователь находится на форме регистрации.
    + Пользователь вводит уникальный логин и валидный пароль. (не менее 8 символов пароль и не менее 8 символов логин).
    + Пользователь авторизуется в системе и перенаправляется в свой личный кабинет.
- **Логин занят:**
    + В системе уже существует пользователь с таким логином.
    + Новый пользователь пытается зарегистрироваться с таким же логином.
    + Регистрация отклоняется, выводится сообщение об ошибке “Пользователь с таким логином уже существует”.
- **Не валидный пароль:**
    + Новый пользователь вводит пароль короче 8 символов.
    + Регистрация отклоняется, выводится сообщение об ошибке “Длина пароля должна быть более 8 символов”.

## Авторизация

**Как зарегистрированный пользователь, я хочу войти по логину и паролю, чтобы получить доступ к личному кабинету.**

Критерии приемки:

- **Успешная авторизация:**
    + Пользователь имеет аккаунт и находится на форме авторизации.
    + Пользователь вводит корректные логин и пароль.
    + Пользователь авторизуется и перенаправляется на страницу профиля.
- **Неверные данные:**
    + Пользователь вводит неверный логин или пароль.
    + Авторизация отклоняется, и выводится сообщение об ошибке “Неверный логин или пароль”.

## Фильтрация курсов

**Как пользователь я хочу отфильтровать список курсов по категории, чтобы быстрее найти нужный курс.**

Критерии приемки:

- **Успешный поиск:**
    + Пользователь выбирает нужную ему категорию из списка существующих категорий.
    + Курсы соответствующие данной категории отображаются пользователю.
    + Если курсов с такой категорией нет, пользователь видит надпись: Курсов в данной категории нет.

## Просмотр информации о курсе

**Как пользователь я хочу открыть карточку курса, чтобы ознакомиться с программой и понять, подходит ли мне этот курс.**

Критерии приемки:

- **Успешный поиск:**
    + Пользователь выбирает нужный курс и видит краткую информацию о нем: Название курса, описание, категории которым
      принадлежит курс, дату создания и краткий список модулей курса: название, и порядок модулей.
    + Для дальнейшего изучения структуры курса необходимо быть записанным на него.

# Роль: Преподаватель

Для выполнения всех дальнейших действий необходимо быть зарегистрированным и аутентифицированным в системе, иначе
пользователь при выполнении дальнейших действий будет получать ошибку с следующим описанием: Для выполнения данного
действия необходимо быть зарегистрированным в системе. Роль преподавателя имеет каждый пользователь для курсов, автором
которых он является.

## Создание курса

**Как преподаватель, я хочу создавать пустой курс (черновик), чтобы заложить основу для добавления учебных материалов.**

Критерии приемки:

- **Успешное создание:**
    + Преподаватель находится на странице создания курса.
    + Он заполняет обязательные поля (Название) и необязательные (описание, теги) и нажимает “Создать”.
    + Создается курс со статусом черновик, он отображается в профиле преподавателя.
- **Ошибки валидации:**
    + Поле “название курса” не заполнено.
    + Курс не создается, выводится ошибка с текстом “Не все обязательные поля заполнены”.

# Редактирование курса

## Создание модулей

**Как преподаватель, я хочу создавать пустой модуль в (черновик) для дальнейшего добавления в него уроков и заданий.**

Критерии приемки:

- **Успешное создание:**
    + Преподаватель находится на странице редактирования курса.
    + Он нажимает “Добавить модуль” и заполняет обязательное поле “Название модуля”.
    + Создается новый модуль в статусе черновик, он виден в структуре курса.
- **Ошибки валидации:**
    + Поле “Название модуля” не заполнено.
    + Новый модуль не создается, выводится ошибка с текстом “Не все обязательные поля заполнены”.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Новый модуль не создается, и выводится ошибка с текстом “У вас нет нужных прав доступа”.
- **Проверка курса:**
    + Пользователь хочет добавить модуль в курс, который находится в архиве.
    + Новый модуль не создается, и выводится ошибка с текстом “Данный курс находится в архиве”.

## Создание уроков

**Как преподаватель, я хочу создавать уроки в модулях (черновики) чтобы в дальнейшем дополнить материал и опубликовать
его.**

Критерии приемки:

    + Преподаватель находится на странице модуля в черновике курса.
    + Нажимает “добавить урок”, указывает название урока.
    + Урок создается в статусе черновик и привязывается к текущему модулю.
- **Ошибки валидации:**
    + Преподаватель пытается создать урок, не заполнив основные поля.
    + Выводится ошибка с текстом “Не все обязательные поля заполнены”.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Урок не создается, и выводится ошибка с текстом “У вас нет нужных прав доступа”.
- **Проверка курса:**
    + Пользователь хочет добавить урок в курс, который находится в архиве.
    + Новый урок не создается, и выводится ошибка с текстом “Данный курс находится в архиве”.

## Создание тестов

**Как преподаватель, я хочу создавать тесты в модулях в (черновики) чтобы в дальнейшем дополнить материалом и
опубликовать его.**

Критерии приемки:

- **Успешное создание:**
    + Преподаватель находится на странице редактирования модуля.
    + Нажимает “добавить тест”, настраивает его параметры и добавляет вопросы. Для создания теста обязательное должно
      быть указано его название, опционально - описание. Также тест должен удовлетворять следующему условию: в тесте
      содержится не менее 1 вопроса и в вопросе содержится не менее 2-х вариантов ответа.
    + Тест создается в статусе черновик.
- **Ошибки валидации:**
    + Преподаватель пытается создать тест, в котором содержится менее 1 вопроса, или в вопросе содержится менее 2-х
      вариантов ответа, или не заполнено обязательное поле: название.
    + Выводится ошибка с текстом “Введенные данные некорректны”.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Тест не создается, и выводится ошибка с текстом “У вас нет нужных прав доступа”.
- **Проверка курса:**
    + Пользователь хочет добавить тест в курс, который находится в архиве.
    + Новый тест не создается, и выводится ошибка с текстом “Данный курс находится в архиве”.

## Удаление тестов

**

Критерии приемки:

- **Успешное удаление:**
    + Преподаватель находится на странице редактирования курса.
    + Нажимает “Удалить тест” и подтверждает его удаление.
    + Тест удаляется из модуля, структура курса обновляется.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Удаление теста отклоняется, и выводится ошибка с текстом “У вас нет нужных прав доступа”.
- **Проверка курса:**

    + Тест не удаляется, и выводится ошибка с текстом “Данный курс находится в архиве”.
- **Каскадное удаление:**
    + Тест был пройден студентами.
    + Преподаватель удаляет тест.
    + Прогресс и попытки студентов также удаляются.

**Как преподаватель, я хочу удалять пустые модули чтобы поддерживать курс в актуальном состоянии.**

Критерии приемки:

- **Успешное удаление:**
    + Модуль не содержит ни одного урока или теста.
    + Преподаватель нажимает “Удалить модуль” и подтверждает удаление.
    + Удаление выполняется, структура курса обновляется.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.

- **Запрет удаления непустого модуля:**
    + В модуле есть хотя бы один урок/тест.
    + Преподаватель пытается удалить данный модуль.
    + Удаление отклоняется, выводится ошибка с текстом “Нельзя удалить модуль, в котором есть уроки или тесты”.

## Публикация модулей

**Как преподаватель, я хочу публиковать модули вместе со всем их содержимым чтобы развивать курс.**

Критерии приемки:

- **Успешная публикация модуля:**
    + Преподаватель находится в редакторе курса.
    + Преподаватель нажимает “Опубликовать” рядом с конкретным модулем и подтверждает публикацию.
    + Модуль становится видимым для студентов со всем содержимым (тесты и уроки).
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Публикация модуля отклоняется, и выводится ошибка с текстом “У вас нет нужных прав доступа”.
- **Проверка курса:**
    + Пользователь хочет опубликовать модуль в курсе, который находится в состоянии архив/черновик.
    + Модуль не публикуется, и выводится ошибка с текстом “Данный курс находится в архиве” или “Данный курс находится в
      статусе черновик”.
- **Запрет публикации пустого модуля:**
    + В модуле нет ни одного урока/теста.
    + Преподаватель пытается опубликовать данный модуль.
    + Публикация не выполняется, выводится ошибка с текстом “Нельзя опубликовать пустой модуль”.

    + Урок становится видимым для студентов со всем содержимым (тесты и контент).
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.

    + Урок не публикуется, и выводится ошибка с текстом “Данный курс находится в архиве”, “Данный курс находится в
      статусе черновик”.
- **Зависимость от родительского модуля:**
    + Модуль в котором находится данный урок, еще не опубликован.
    + Преподаватель пытается опубликовать урок.
    + Публикация не выполняется, выводится ошибка с текстом “Сначала опубликуйте модуль”.

    + Публикация не выполняется, выводится ошибка с текстом “Сначала опубликуйте модуль”.
- **Ошибки валидации:**
    + В тесте нет ни одного вопроса.
    + Преподаватель пытается его опубликовать.
    + Тест не публикуется, и выводится ошибка с текстом “Нельзя опубликовать тест без вопросов”.

## Публикация курса

**Как преподаватель, я хочу публиковать курс со всем его содержимым, чтобы он появился в поиске и студенты могли на него
записаться.**

Критерии приемки:

- **Успешная публикация:**
    + Курс имеет статус черновик.
    + Преподаватель нажимает “Опубликовать” и подтверждает публикацию.
    + Курс становится видимым для студентов вместе с содержимым курса.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Публикация курса отклоняется, и выводится ошибка с текстом “У вас нет нужных прав доступа”.
- **Проверка курса:**
    + Пользователь хочет опубликовать курс, который находится в архиве.
    + Курс не публикуется, и выводится ошибка с текстом “Данный курс находится в архиве”.
- **Запрет публикации пустого курса:**
    + В курсе нет контента (модулей).
    + Преподаватель пытается его опубликовать.
    + Курс не публикуется, и выводится ошибка с текстом “Нельзя опубликовать пустой курс”.

## Просмотр статистики курса

**Как преподаватель, я хочу видеть список студентов, прошедших урок, чтобы понимать, какая часть аудитории изучила
материал.**

Критерии приемки:

- **Успешный просмотр:**
    + Преподаватель - владелец курса. На курсе есть записанные студенты.
    + Он открывает страницу статистики конкретного урока.
    + Преподаватель видит список студентов с их статусами прохождения (Пройден, не начат, в процессе).
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Преподаватель не может посмотреть статистику урока, курса, владельцем которого не является. Выводится ошибка с
      текстом “У вас нет нужных прав доступа”.

**Как преподаватель, я хочу видеть список пользователей, прошедших определенный тест, чтобы понимать, какая часть
аудитории выполнила тест и какая часть успешно его прошла.**

Критерии приемки:

- **Успешный просмотр:**
    + Тест опубликован, студенты приступили к его выполнению.
    + Преподаватель открывает страницу статистики конкретного теста.
    + Преподаватель видит сводные данные: общее количество попыток, процент успешных прохождений (сдавших) и список
      студентов с их индивидуальными результатами.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Преподаватель не может посмотреть статистику теста, курса, владельцем которого не является. Выводится ошибка с
      текстом “У вас нет нужных прав доступа”.
- **Разделение статусов:**
    + Студент начал тест, но не завершил его.
    + Преподаватель смотрит статистику.
    + Студент отображается в статусе “в процессе”.

**Как преподаватель, я хочу видеть ответы конкретного студента на тест, чтобы понять, в каких темах он ошибается, и дать
обратную связь.**

Критерии приемки:

- **Успешный просмотр:**
    + Студент завершил тест. Преподаватель находится в списке статистики теста.
    + Он нажимает на имя конкретного студента.
    + Открывается детальный отчет: список вопросов, ответы студента (правильные выделены зеленым, неправильные —
      красным), правильные варианты ответов и затраченное время.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Преподаватель не может посмотреть ответы конкретного студента, курса, владельцем которого не является. Выводится
      ошибка с текстом “У вас нет нужных прав доступа”.

## Перенос курса в архив

**Как преподаватель, я хочу переводить курс в статус "Архив", чтобы закрыть набор новых студентов, но сохранить доступ к
материалам для уже купивших.**

Критерии приемки:

- **Успешная архивация:**
    + Преподаватель - владелец курса. Курс находится в статусе “опубликован”.
    + Преподаватель нажимает кнопку «Перенести в архив» и подтверждает действие.
    + Статус курса меняется на “в архиве”. Курс исчезает из общего каталога и становится недоступным для записи.
- **Проверка прав доступа:**
    + Пользователь не является владельцем данного курса.
    + Преподаватель не может перенести курс в архив, курса, владельцем которого не является. Выводится ошибка с текстом
      “У вас нет нужных прав доступа”.
- **Сохранения для старых студентов:**
    + Студент уже записан на этот курс.
    + Курс переходит в статус “Архив”.
    + Студент по прежнему видит курс в личном кабинете, может просматривать уроки и проходить тесты.
- **Запрет на редактирование контента:**
    + Курс находится в статусе “Архив”.
    + Преподаватель пытается добавить, изменить или удалить модуль, урок или тест.
    + Операция не выполняется, выводится ошибка с текстом “Архивные курсы не изменяемы”.
- **Валидация статусов:**
    + Преподаватель пытается архивировать курс, который находится в статусе “черновик”.
    + Операция блокируется с сообщением «Нельзя архивировать черновик. Сначала опубликуйте курс».

# Роль: Студент

Для выполнения всех дальнейших действий необходимо быть зарегистрированным и аутентифицированным в системе, иначе
пользователь при выполнении дальнейших действий будет получать ошибку с следующим описанием: Для выполнения данного
действия необходимо быть зарегистрированным в системе. Роль студента имеют все пользователи, записанные на данный курс.

## Запись на курс

**Как студент, хочу записаться на курс, чтобы начать обучение.**

Критерии приемки:

- **Успешная запись:**
    + Курс находится в статусе опубликован. Пользователь нажимает на кнопку “записаться” и получает доступ к данному
      курсу.
- **Курс находится в статусе черновик/архив:**
    + Пользователь получает сообщение: “Записать можно только на опубликованные курсы”.

## Прохождение урока

**Как студент, я хочу читать текстовые материалы и смотреть видео в уроке, чтобы осваивать новую тему.**

Критерии приемки:

- **Успешный поиск:**
    + Студент записан на курс, урок находится в статусе опубликован. Студент выбирает нужный ему урок в данном курсе и
      нажимает на него. После нажатия открывается урок и студент видит его содержимое.
- **Студент не записан на курс:**
    + Студент получает сообщение: Для просмотра содержимого урока необходимо быть записанным на курс.
- **Урок не находится в статусе опубликован:**
    + Студент получает сообщение: Данный урок не является опубликованным.

**Как студент, я хочу отмечать пройденные (завершать их), чтобы наглядно видеть свой прогресс по курсу.**

Критерии приемки:

- **Успешное завершение урока:**
    + Студент записан на курс, урок находится в статусе опубликован. Студент нажимает на кнопку: Завершить урок. Урок
      помечается пройденным. При дальнейшем просмотре уроков/курса студент будет видеть что данный урок пройден. Над
      уроком появится надпись: Пройден.
- **Студент не записан на курс:**
    + Студент получает сообщение: Для просмотра содержимого урока необходимо быть записанным на курс.
- **Урок не находится в статусе опубликован:**
    + Студент получает сообщение: Данный урок не является опубликованным.

## Прохождение теста

**Как студент я хочу проходить тесты для прохождения курса и проверки своих знаний.**

Критерии приемки:

- **Успешное прохождение теста:**
    + Студент записан на курс, тест находится в статусе опубликован. Студент нажимает на кнопку: Начать тест. Студент
      видит набор вопросов и дает на них ответы, после чего нажимает на кнопку: Завершить тест. После завершения теста
      студент видит свой балл за него и может посмотреть свои ответы и увидеть какие были правильными а какие нет.
- **Студент не записан на курс:**
    + Студент получает сообщение: Для просмотра содержимого урока необходимо быть записанным на курс.
- **Тест не находится в статусе опубликован:**
    + Студент получает сообщение: Данный тест не является опубликованным.

## Просмотр своей статистики обучения

**Как студент я хочу просматривать статистику завершенных уроков чтобы видеть свой прогресс.**

Критерии приемки:

- **Успешный просмотр:**
    + Студент аутентифицирован и записан на курс. Студент при нажатии в профиле на данный курс видит на каждом уроке
      его прогресс прохождения: пройден урок или нет.
- **Студент не записан на курс:**
    + Студент получает сообщение: Для просмотра содержимого урока необходимо быть записанным на курс.

**Как студент я хочу просматривать статистику пройденных тестов чтобы видеть свой прогресс.**

Критерии приемки:

- **Успешный поиск:**
    + Студент записан на курс, тест опубликован и студент прошел данный тест. Студент может нажать на кнопку:
      Посмотреть результат и увидит вопросы в тесты, свои ответы на них и увидит цветовое разделение на правильные и
      неправильные ответы (Неправильные будут подсвечиваться красным, правильные - зеленым).
- **Студент не зарегистрирован:**
    + Студент получает сообщение: Для просмотра содержимого урока необходимо быть зарегистрированным.
- **Студент не записан на курс:**
    + Студент получает сообщение: Для просмотра содержимого урока необходимо быть записанным на курс.
- **Тест не находится в статусе опубликован:**
    + Студент получает сообщение: Данный урок не является опубликованным.
- **Студент не прошел тест:**
    + Студент получает сообщение: Данный тест не пройден. Пройдите тест чтобы получить информацию о попытке.
