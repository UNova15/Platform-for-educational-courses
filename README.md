# Проект: Платформа образовательных курсов Kira

Проект находится в стадии активной разработки, не все описаные требования выполнены на данный момент

## Функциональные требования:

### Роль: Неавторизованный пользователь (Гость):

- Регистрация пользователя.
- Вход в аккаунт по login и паролю.
- Просмотр каталога опубликованных курсов с фильтрацией по категориям.
- Поиск курсов по названию/категории.

### Роль: Ученик:

- Наследует права Гостя.

- Возможность просмотра профиля. В профиле отображается количество пройденных крусов, количество активных курсов,
  оценки, ближайщие дедлайны.

- Запись на открытые курсы

- Отправка заявки на запись на закрытые курсы

- Просмотр своих курсов с отображением прогресса.
- Прохождение курса:

    - Просмотр уроков курса. Урок может содержать текст, видео, файлы. После просмотра урока, он помечается как
      посмотренный. Курс считается пройденным если пройдены все обязательные уроки и выполнены все обязательные задания.

    - Прохождение тестов и заданий с развернутым ответом. При прохождении теста оценка выставляется автоматически. При
      отправки задания с развернутым ответом преподаватель может его проверить и выставить оценку.
    - Ученик может отправлять преподавателю комментарии к своей работе.

### Роль: Преподаватель:

- Наследует права Пользователя.
- Просмотр входящих заявок на свои закрытые курсы. Возможность одобрить/отклонить заявку

- Создание и управление курсами:

    - Добавление модулей, уроков, заданий с авто/ручной проверкой.
    - Редактирование модулей уроков, заданий с авто/ручной проверкой.
    - Удаление курсов, модулей, уроков, заданий с авто/ручной проверкой.

- Управление учениками на своих курсах:

    - Просмотр списка учеников.

    - Оценка выполненных учениками заданий.
  
    - Изменение оценок за выполненные задания - перепроверка.

    - Оставление комментариев к работам учеников.

    - Приглашение учеников на закрытый курс по email (генерация уникальной ссылки - приглашения. Ссылка
      может быть ограничена по времени,
      является общей для приглашения всех учеников ).
      После перехода по ссылке пользователь должен зарегистрироваться (если уже не зарегистрирован)

## Нефункциональные требования:

- Кэширование:<br>
  Использование кеширования для каталога курсов, чтобы снизить нагрузку на БД (Valkey).

- Мониторинг и метрики:<br>
  Использование Spring Boot Actuator, интеграция с Prometheus и Grafana.

- Документация API:<br>
  Swagger/OpenAPI с подробным описанием эндпоинтов и моделей.

- Тестирование:<br>
  Unit-тесты (JUnit, Mockito), интеграционные тесты с Testcontainers.

- CI/CD:<br>
  Автоматическая сборка, запуск тестов, сборка Docker-образа при добавлении в репозиторий (Github Actions).

- Безопасность:<br>
    - Разграничение прав доступа к ресурсам (аутентификация).

    - Шифрование паролей.
    - Защита от CSRF для браузерных клиентов, CORS политики.

    - Проверка прав доступа на уровне методов
    - Валидация входящих данных
    - Ограничение количества запросов - Rate Limiting для защиты от брутфорса и DDoS.

- Надежность и Масштабируемость:<br>

    - Структурное логирование

    - Обработка возникающих ошибок

    - Асинхронность "тяжелых" операций (отправка писем, конвертация видео, генерация отчетов).

## Планируемые дополнительные функции:

-[ ] Загрузка учениками файлов с выполненным заданием для проверки преподавателем, загрузка преподавателями файлов (в
 том числе видео).

-[ ] Получение учениками уведомлений на email и в интерфейсе приложения о проверке работы, новом материале, дедлайнах.
 Получение преподавателями уведомлений о записях на курс, заявках на запись, о выполненных заданиях.

-[ ] Отправка сообщений преподавателю в рамках курса (чат с преподавателем), ответы преподавателями на сообщения
 учеников в рамках курса.

-[ ] Возможность проведения онлайн встреч (Проведение онлайн конференций, лекций и семинаров).
