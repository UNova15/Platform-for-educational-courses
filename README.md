# Образовательная платформа Kira

## Идея проекта

Создание общей платформы для преподавателей и студентов, где преподаватели смогут создавать свои курсы, а студенты их
проходить. Преподавателям будет доступен конструктор курсов. На платформе будут объединены все необходимое для
проведения обучения и создания курсов. Планируется добавление чата с преподавателем, добавление общей платформы для
проведения семинаров

## Стек технологий

### Backend:

* Java 25
* Spring Boot 4, Spring data Jdbc, Spring security
* PostgresQL
* MiniO (Еще не реализован)

### Frontend (Реализуется в данный момент):

* TS
* React

### Infrastructure:

* docker
* docker compose

## Инструкция по запуску

* Установить docker и docker compose
* Создать файл .env
* Скопировать в .env файл содержимое файла .env.example и изменить переменные при необходимости:
  `cp .env.example .env`
* Запуск командой:
  `docker compose up --build`

### API доступен по адресу: http://localhost:8080/api

### Документация Swagger UI: http://localhost:8080/api/swagger-ui.html
